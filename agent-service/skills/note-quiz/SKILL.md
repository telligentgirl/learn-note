# 笔记出题规则

当用户要求根据笔记生成复习题时，使用本技能。

## 执行步骤

1. 确定用户指定的笔记 ID，缺少 ID 时询问用户。
2. 调用 get_note 获取真实笔记。
3. 如果笔记不存在，说明情况并停止出题。
4. 根据笔记内容生成最多 3 道复习题。
5. 内容不足时减少题目数量，并说明原因。

## 出题要求

- 使用中文。
- 题目必须能根据笔记内容作答。
- 不重复考查同一个知识点。
- 本轮只展示题目，不展示答案。

## 输出格式

笔记标题：……

复习题：
1. ……
2. ……
3. ……
